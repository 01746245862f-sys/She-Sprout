# She and Sprout Website

A simple, mobile-friendly static website ready to deploy on Vercel.

## Deploy to Vercel

1. Put these files in a GitHub repository:
   - `index.html`
   - `style.css`
   - `README.md`

2. Go to https://vercel.com and sign in.

3. Click **Add New → Project**.

4. Import your GitHub repository.

5. Leave the build settings as default:
   - Framework preset: **Other**
   - Build command: leave blank
   - Output directory: leave blank

6. Click **Deploy**.

Vercel will give you a live link such as `https://she-and-sprout.vercel.app`.

## Customize

- Replace the email, phone number, and location in `index.html`.
- Replace the About and Services text with your real business details.
- Add product photos in a new folder called `images/`, then use:
  `<img src="images/your-photo.jpg" alt="Product name">`
